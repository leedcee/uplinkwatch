# Security policy

## Supported versions

Security fixes are applied to the latest released version of UplinkWatch.

## Reporting a vulnerability

Do not publish credentials, browser history, private URLs, or exploit details
in a public issue. Use GitHub's private vulnerability reporting feature when it
is enabled for the repository. Otherwise, open a minimal issue asking the
maintainer for a private contact channel without including sensitive details.

Include the affected version, operating system, impact, and reproduction steps
that do not expose private data.
