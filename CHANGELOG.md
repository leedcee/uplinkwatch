# Changelog

All notable changes to UplinkWatch will be documented in this file.

## Unreleased

- No unreleased changes yet.

## 0.1.0 - 2026-10-16

- Implemented staged DNS, TCP, TLS, and HTTP reachability checks.
- Added a local web dashboard, JSON API, health endpoint, and Prometheus metrics.
- Added one combined Arc, Chrome, Edge, Brave, and Firefox discovery flow for Windows.
- Added best-effort local failure diagnosis.
- Added GitHub Actions for Windows and Linux validation.
- Added automated tagged Windows release archives with SHA-256 checksums.
- Added Prometheus, Grafana, and Alertmanager deployment configuration.
- Added an SLO dashboard, alert rules, and operational runbooks.
- Added build version information through `--version`.
